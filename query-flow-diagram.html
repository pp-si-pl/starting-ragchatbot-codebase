    User->>FE: Types question & clicks Send
    activate FE
    FE->>FE: addMessage(query, 'user')
    FE->>FE: Show loading animation

    FE->>+API: POST /api/query
{query, session_id: null}
    deactivate FE

    Note over API: session_id is null → create new session
    API->>+SM: create_session()
    SM-->>-API: "session_1"

    API->>+RAG: query(query, "session_1")

    RAG->>RAG: Wrap prompt:
"Answer this question about
course materials: {query}"

    RAG->>+SM: get_conversation_history("session_1")
    SM-->>-RAG: None (first message)

    RAG->>+AI: generate_response(prompt, history,
tool_definitions, tool_manager)

    Note over AI: Build system prompt +
conversation history (if any)

    AI->>+Claude: messages.create()
model, system, messages, tools
    Claude-->>-AI: Response with stop_reason

    alt stop_reason == "end_turn"
        Note over AI: Claude answered directly
without searching
        AI-->>RAG: response text
    else stop_reason == "tool_use"
        Note over AI,Claude: Claude wants to search
course content

        rect rgb(30, 60, 90)
            Note over AI,DB: Tool Execution Phase

            loop For each tool_use block
                AI->>+TM: execute_tool("search_course_content",
query, course_name?, lesson_number?)
                TM->>+CST: execute(query, course_name, lesson_number)

                CST->>+VS: search(query, course_name, lesson_number)

                opt course_name provided
                    VS->>+DB: query course_catalog
(fuzzy name match)
                    DB-->>-VS: resolved course_title
                end

                VS->>VS: _build_filter(course_title, lesson_number)

                VS->>+DB: query course_content
(semantic search, n=5)
                Note over DB: Embed query with
all-MiniLM-L6-v2
→ cosine similarity
                DB-->>-VS: top 5 matching chunks
+ metadata + distances

                VS-->>-CST: SearchResults

                CST->>CST: _format_results()
Store sources in last_sources

                CST-->>-TM: formatted result string
                TM-->>-AI: tool_result
            end

            AI->>+Claude: 2nd API call
(messages + tool results,
NO tools this time)
            Note over Claude: Claude synthesizes
final answer from
search results
            Claude-->>-AI: final response text
        end

        AI-->>-RAG: response text
    end

    RAG->>+TM: get_last_sources()
    TM-->>-RAG: ["Course X - Lesson Y", ...]

    RAG->>TM: reset_sources()

    RAG->>+SM: add_exchange("session_1",
user_query, ai_response)
    SM-->>-RAG: (saved)

    RAG-->>-API: (response, sources)

    API-->>-FE: JSON response:
{answer, sources, session_id}

    activate FE
    FE->>FE: Remove loading animation
    FE->>FE: marked.parse(answer) → HTML
    FE->>FE: addMessage(answer, 'assistant', sources)
    FE->>FE: Render collapsible sources panel
    FE-->>User: Display formatted answer
    deactivate FE
